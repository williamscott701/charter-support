# charter-support

Public support site for **Charter**, an independent study planner for the CFA® exams.

Served by GitHub Pages at <https://williamscott701.github.io/charter-support/>.
These three URLs go into App Store Connect:

| Page | URL | Used for |
|---|---|---|
| Support | `/charter-support/` | App Store *Support URL* |
| Privacy | `/charter-support/privacy.html` | App Store *Privacy Policy URL* (required) |
| Terms | `/charter-support/terms.html` | App Store *EULA / Terms* link |

The pages are generated by `.build-site.py` so the palette, typography and footer
cannot drift between them. Edit the content in that script and re-run it:

```bash
python3 .build-site.py
```

Charter itself lives in a separate private repo. Nothing here is part of the app
bundle — the app links out to these pages from Settings and the paywall.
